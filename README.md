# n8n-daily-digest

An n8n workflow that emails you every morning with an AI summary of the new videos from the YouTube channels you follow. One email, summaries first, then the videos it could not summarize and why.

I built it for people who follow a few channels for work (tech news, a competitor, a niche) and want to know what came out overnight and whether it is worth watching. The file is `daily-youtube-digest.json`, 25 nodes, no credentials inside.

## What it does

1. At 7 am it asks the YouTube Data API for the latest uploads of each channel in your list. Each channel's uploads playlist is derived from the channel ID, so no search quota is spent.
2. It drops live streams, premieres that have not aired and videos under 3 minutes (most Shorts), keeps the ones from the last 48 hours, and skips anything it already sent you. The dedupe uses n8n's Remove Duplicates node across executions, so each video goes out once.
3. One Apify run fetches the transcripts for the whole batch.
4. OpenAI writes a summary per video: a TL;DR, three to five key points, a verdict (must watch, worth a skim, skip) and who it is for. A structured output parser forces the same fields every time so the email layout holds.
5. Gmail sends the digest. Videos without a transcript are listed with the reason (no captions, private, members-only). Channels that could not be read are listed too, so nothing disappears without a note.

Days with no new videos send nothing. A run only fails outright if every channel is unreadable, which almost always means the API key.

## What it costs

- YouTube Data API v3: free. A run with 10 channels uses about 11 of the 10,000 daily quota units.
- Transcripts come from an Apify actor I publish, [youtube-transcript-scraper](https://apify.com/beacondata/youtube-transcript-scraper), at $0.002 per video. Videos without captions are not charged. If you would rather use something else, change the URL in **Fetch transcripts** and the field names in **Match transcripts to videos** (`videoId`, `text`, `error`, `errorType`, `isAutoGenerated`).
- OpenAI: the default model is gpt-5-mini, which costs well under a cent per video. Any chat model node works in its place.
- Gmail: free. Swap the last node for Slack or Outlook if you prefer.

## Import

1. In n8n open Workflows, click the arrow next to Create Workflow and pick Import from File, then choose `daily-youtube-digest.json`.
2. Open **Config** and set `channelIds` (comma separated, each starts with `UC`; on a channel page click "more", then Share channel, then Copy channel ID) and `recipientEmail`.
3. YouTube: in Google Cloud Console enable YouTube Data API v3 for a project and create an API key. In n8n create a **Query Auth** credential with Name `key` and the API key as Value, then select it on **Get latest uploads** and **Get video details**.
4. Apify: copy your API token from Apify Console, Settings, API & Integrations. Create a **Header Auth** credential with Name `Authorization` and Value `Bearer YOUR_TOKEN`, then select it on **Fetch transcripts**.
5. Select your OpenAI credential on **OpenAI Chat Model** and your Gmail credential on **Send digest**.
6. Run it once by hand. The first run sends the videos from the last 48 hours. Then activate it.

The schedule, the 48-hour window, the cap per run (`maxVideosPerRun`) and the minimum length (`minDurationSeconds`) are all in **Config**.

## Notes on the build

- The Code nodes avoid expressions on values that may be missing. A channel that returns an error passes through as an item with an `error` field (the HTTP nodes are set to continue on error), and the last Code node turns those into the "could not be read" list.
- The email HTML is assembled by a small `tag()` helper at run time rather than written as literal markup, because the n8n template portal refuses workflow JSON that contains HTML tags.
- The Gmail node retries three times, five seconds apart.
- Tested on n8n 2.42.5 against a mock of the three APIs, nine scenarios: a first run with an unknown channel and a video without captions in the mix, a day with nothing new, a premiere that airs a day later, Apify down, the model failing on one video, the YouTube quota gone (that run fails and the next day's run picks the videos up), a handle pasted instead of a channel ID, and a cap of one video per run.
